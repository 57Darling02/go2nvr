# Screenshot Guide

把 README 中使用的 WebUI 截图放在这个目录。

推荐文件：

- `dashboard.png`：Dashboard 总览，展示左侧导航、视频宫格、录像状态和操作按钮。
- `live-control-tts.png`：Live Control 页面，展示实时视频和 TTS Push 面板。
- `recordings.png`：Recordings 页面，展示录像列表、缩略图、播放器、下载和删除按钮。
- `record-rule.png`：Record Rule 弹窗，展示预录制、运动触发和触发参数。
- `add-stream.png`：Add Stream 弹窗，展示 RTSP/ONVIF 接入。
- `config-system.png`：配置编辑器或系统日志页面，可选。

建议优先使用桌面宽屏截图，宽度控制在 1400 到 1800 像素之间。截图里可以使用测试摄像头或打码后的真实地址，避免暴露家庭网络、账号、公网域名和精确位置。
